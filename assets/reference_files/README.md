# Quant Research Workbench 线上生产回归参考包

## 目的

这套文件用于线上生产回归，也作为 App“参考文件”页的静态下载资源。所有数据均为确定性合成数据，不对应任何真实证券、账户、机构或投资结果，也不代表真实投资收益。

目录内的 `.gitattributes` 禁止 Git 转换静态资源的换行字节，确保 Windows、Linux 和云端检出的文件与 manifest 中的 SHA-256 保持一致。

App 只返回仓库文件的原始字节。下载前会按 `manifest.json` 核对文件大小和 SHA-256；不会重新导出 CSV、重写 XLSX、自动上传、自动映射或自动分析。

## 推荐回归顺序

1. `01_standard_returns_with_benchmark.csv`
   - 使用“按现有标准协议上传”
   - 应直接进入现有收益率分析
   - 应显示基准对比、报告和下载

2. `02_standard_returns_no_benchmark.csv`
   - 使用“按现有标准协议上传”
   - 应按无基准流程分析
   - 不应生成虚假基准

3. `03_generic_cn_returns.csv`
   - 使用“通用文件导入（CSV/XLSX）”
   - 选择“策略收益率为主”
   - 映射：交易日期→date；策略收益率→strategy_return；基准收益率→benchmark_return
   - 完成读取、建议、确认、标准化、预检、严格验证、最终分析

4. `04_generic_cn_nav.csv`
   - 使用“通用文件导入（CSV/XLSX）”
   - 选择“策略净值为主”
   - 映射：交易日期→date；组合净值→strategy_nav
   - 辅助日收益首行为空，仅供查看；为了按现有 B.4A 规则完成分析，不要映射该可选字段

5. `11_multi_sheet_online_regression.xlsx`
   - 验证多工作表选择
   - 切换工作表后，旧映射、标准化预览、严格验证和分析结果均应失效
   - 有效工作表应通过；错误工作表应在B.4A预检阶段阻断

## 错误文件的预期行为

- `06_error_percent_strings.csv`：收益率含百分号，不得自动除以100；当前会在字段映射确认阶段提示没有可转换数值并阻断。
- `07_error_duplicate_dates.csv`：存在重复日期，不得自动去重，应阻断。
- `08_error_ambiguous_dates.csv`：日期格式含糊，不得按地区习惯猜测，应阻断。
- `09_error_unsorted_dates.csv`：日期非严格递增，不得自动排序，应阻断。
- `10_error_nonpositive_nav.csv`：净值包含0和负数，不得自动归一化或修复，应阻断。

## App 中提供的文件

### “参考文件”区域
- 标准收益率（含基准）
- 标准收益率（无基准）
- 中文通用收益率
- 中文通用净值
- 英文通用收益率
- 多工作表 XLSX

### “错误示例与预检说明”折叠区域
- 百分号收益率
- 重复日期
- 含糊日期
- 日期倒序
- 非正净值

错误示例下载按钮旁应明确写明：这些文件用于演示系统如何阻断不安全或不明确的数据，不应被视为可分析模板。

## App 集成边界

文件固定存放于 `assets/reference_files/`，下载元数据来自只读清单 `catalog.json`。App 不扫描参考目录之外的位置，不接受绝对路径或 `..`，也不会在服务器端修改这些文件。每个按钮旁显示：
- 文件用途
- 推荐入口
- 推荐主口径
- 是否应通过
- 关键字段映射
- 数据为合成示例的声明

不要把错误示例和有效模板放在同一个默认下载列表中。

下载后的文件仍需由用户主动前往相应入口上传，并自行核对字段定义、单位、主口径和分析范围。错误示例只用于理解阻断机制，不应作为正常分析模板。
