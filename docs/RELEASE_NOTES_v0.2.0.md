# Quant Research Workbench v0.2.0

## 本版本是什么

v0.2.0 是首个包含完整通用文件导入工作流和参考文件库的公开功能版本。网站可用于上传和检查策略收益或净值数据、计算并展示基础绩效、比较多个实验、导出可复核报告，以及学习标准数据格式和错误阻断机制。

本工具用于研究记录和结果核验，不构成投资建议，也不保证任何策略的收益或有效性。

## 核心新增功能

### 1. 通用 CSV/XLSX 导入

- 支持读取 CSV 和 XLSX。
- 支持 UTF-8 BOM、UTF-8 和 GB18030 CSV 编码。
- 支持有限、明确的 CSV 分隔符识别和手动选择。
- 支持用户选择 Excel 工作表。
- 读取成功后只展示文件信息、字段检查和预览，不会自动进入分析。

### 2. 字段建议与用户确认

- 根据字段名称和有界数据画像生成确定性、可解释、可重复的建议。
- 用户必须明确选择策略收益率或策略净值主口径。
- 用户必须核对并确认字段映射。
- 系统不会因为置信度较高而静默确认字段，也不会猜测收益率单位。

### 3. 标准化和数据质量预检

- 根据已确认映射创建独立的新内存 DataFrame。
- 不修改原始文件、原始 DataFrame、列名、索引、行数或行顺序。
- 不自动排序、去重、填充、删行、截断或重采样。
- 明确展示阻断问题和需要人工核对的 warning。
- 预检只验证结构与数据质量，不验证投资可靠性。

### 4. 严格分析门禁

- 标准化预检通过后，仍需用户主动执行现有严格协议验证。
- 严格验证通过后，用户还必须再次确认日期、字段定义、单位、主口径和分析范围。
- 只有点击“开始绩效分析”后才生成指标、图表、摘要、报告和标准化数据下载。
- 收益率路径和净值路径复用现有严格协议和分析逻辑。

### 5. 参考文件库

- 提供 6 个正常参考文件和 5 个故意包含问题的错误示例。
- 所有参考文件均为确定性合成数据，不对应真实证券、账户、机构或投资结果。
- 错误示例用于理解系统的阻断行为，不应作为正常分析模板。
- 下载前会验证仓库静态文件的大小和 SHA-256。
- 下载不会自动上传、建立字段映射或启动分析。

## 支持的输入

- 标准日收益 CSV，可选 `benchmark_return`。
- 每周调仓净值 CSV，可选 `daily_ret` 作为净值一致性辅助字段。
- 通用 CSV。
- 通用 XLSX，用户选择一个工作表。
- 多实验比较所需的标准化分析 CSV。

## 不支持或不会自动执行的内容

- 不自动把 `1` 解释为 `1%`。
- 不自动解析或换算 `1.2%`。
- 不自动处理千分位、货币符号、括号负数、中文数字或万/亿/K/M 单位。
- 不自动修复重复日期或含糊日期。
- 不自动排序、删除错误行或填充缺失值。
- 不自动归一化通用导入中的原始净值。
- 不自动从 `benchmark_nav` 生成 `benchmark_return`。
- 不声称支持任意文件格式或自动理解全部字段。

## 隐私和使用边界

公开云端版本会在云端应用进程中处理上传文件。请勿上传账号密码、API 密钥、交易凭证、个人敏感信息、商业机密或其他受限制数据。敏感研究数据应先脱敏并仅上传完成分析所必需的字段。

当前代码不会主动把上传文件写入项目目录，也不会跨浏览器会话保存文件或字段映射。托管平台、浏览器、代理和基础设施日志不由本项目代码完全控制。

## 已知限制

- 通用导入仅支持 CSV 和 XLSX；不支持 XLS、XLSM、ODS、Parquet、JSON 或 ZIP。
- 当前默认第一行为表头，不自动定位其他表头行。
- `benchmark_nav` 只能用于诊断，不能自动转换为基准收益率。
- 净值主口径当前不扩展基准分析。
- 多实验比较只接受应用生成的标准化 CSV。
- 不提供账号系统、数据库、云端实验历史、实时行情或自动交易。
- 不自动识别百分数单位，也不自动修复用户数据。

## 升级说明

- 原有标准日收益 CSV 无需修改，仍可按现有标准协议直接上传。
- 原有净值文件、单实验分析和多实验比较继续使用相同计算口径。
- 通用 CSV/XLSX 导入是附加入口，不替代现有直接上传流程。
- 现有绩效公式、数据协议、Markdown 报告结构和导出字段没有改变。
- 参考文件可用于学习格式和验证阻断行为，但不能替代对真实数据字段定义与单位的核对。
