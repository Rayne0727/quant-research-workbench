# Quant Research Workbench v0.1.0-rc1 发布检查清单

发布候选版检查应在项目根目录执行：

```powershell
.\scripts\check_release.bat
```

脚本会显示版本、运行全部测试、编译 Python 文件并检查 Git 工作区。工作区不干净时会返回失败；脚本不会启动 Streamlit、提交 Git、删除缓存或结束进程。

## 自动门禁

- [ ] Git 工作区干净。
- [ ] 全部 pytest 通过。
- [ ] `app.py`、`src` 和 `tests` 中的 Python 文件可编译。
- [ ] README 版本号为 `0.1.0-rc1`。
- [ ] 页面版本号为 `0.1.0-rc1`。
- [ ] `requirements.txt` 和 `requirements-dev.txt` 均存在且职责分离。
- [ ] GitHub Actions CI 对 `master` 运行 pytest 和 compileall。
- [ ] CI 不引用 Secrets，不执行发布或部署。

## 单实验回归

- [ ] 单实验示例正常显示指标和两张图。
- [ ] 标准收益 CSV 可以分析。
- [ ] 不含基准的合法收益 CSV 可以分析。
- [ ] 真实每周调仓净值文件可以分析。
- [ ] 真实文件 daily_ret 诊断为 318 次比较、68 次不一致。
- [ ] Markdown 报告和标准化 CSV 下载正常。
- [ ] 标准日频收益模板可以下载且中文说明正常。

## 多实验回归

- [ ] 固定比较示例正常。
- [ ] 两份标准化 CSV 可以比较。
- [ ] 共同日期使用真实日期集合交集。
- [ ] 所有共同区间净值首日为 1。
- [ ] 指标、摘要、净值图和回撤图正常。
- [ ] 三种比较下载正常。
- [ ] 重复实验名称显示中文错误。
- [ ] 错误字段文件显示包含文件名的中文错误。
- [ ] 标准化比较模板可以下载并通过现有验证。
